**Built SOHA's backend and led its AI engineering**, designing and implementing the complete AI pipeline for a live university assistant developed with Shahid Beheshti University's NLP Lab.

- **Knowledge to answers:** document processing → chunking and embeddings → retrieval and ranking → context assembly → agent workflows and response generation.
- **Evaluation and observability:** Ragas for RAG evaluation; Langfuse for tracing and monitoring LLM workflows.
- **Application integration:** authenticated Django/DRF APIs and WebSocket/ASGI communication between the application and AI services.

**Public companion:** [SOHA assistant core →](https://github.com/AmirAliRasoulii/soha-ai-assistant) — architecture, typed contracts and an asynchronous execution baseline under active development.
